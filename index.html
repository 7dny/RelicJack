THE CARDWRIGHT’S GRIMOIRE · COMPLETE GUIDE

Relicjack, fully explained

Tavern & Rank

The Tavern is your home. It shows gold, vault progress, uptime, games, cases, quests, daily blessing, and Cardwright rank. Gain XP from rounds, quests, and cases. Every rank awards gold; every fifth rank grants a free Cardwright’s Cache.

Loadout & Table

Equip five different relics. Each five-round run asks you to choose one before the casino element is revealed. Build bets from multiple chips, then Hit, Stand, or Double. A perfect run means winning all five rounds.

Casino Atlas

Start at Fire. Win five perfect five-round games to defeat a casino and unlock the next elemental Order for Forge drops. The Dealer Journal shows the current casino host and its fair table rule.

Forge & Cases

Cases roll one relic at a time with the reel animation. They only draw from unlocked Orders. Duplicate relics raise level by one. Reward Caches are free one-relic cases earned through ranking.

Relic Library

The Collection Map focuses elemental branches. The Bond Codex shows paired Orders. Filters sort by set, ownership, rarity, and Founder relics. Every relic can be inspected and equipped from its detail panel.

Rarities, Levels & Fusion

Relics have C, R, SR, SSR, UR, and HR rarities. Base relics refine with gold from I to X; duplicate pulls are free upgrades. Two distinct level-X base relics can be consumed in the Fusion Crucible to create one artifact with both perks. Founder artifacts cannot fuse.

Bonds & Set Deeds

Equipping paired elemental Orders activates a small payout bond. Completing all ten relics in an Order records an Order Deed, title, and one-time gold reward. The Hall of Deeds shows all achievement and set rewards, locked or claimed.

Quests & Daily Blessing

Five Daily Decrees refresh each device day; ten Weekly Chronicles refresh each Monday. Claim their gold and XP rewards. Opening the game on a new day grants the Sunrise Boon shown in the Tavern.

Founder & Admin Artifacts

Founder’s Fortune and Founder’s Force are HR level-X artifacts managed only through the Archivist Console. Fortune can create a natural blackjack; Force gives each bust a 50% push chance. They are removable, saved locally, and never fuse.

Other Pages

Run Ledger records recent activity. Arcane Chronicle records updates. Rune Seals accepts reward codes; RJ$ opens the local Admin Console for test tools. The Grimoire is this guide. All progress is stored in this browser’s local storage for offline play.
